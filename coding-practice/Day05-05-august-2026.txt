Ansible — Create User and Set Permissions

- name: Create a new user
  hosts: all
  become: yes
  tasks:
    - name: Create user
      user:
        name: rachna
        state: present
        shell: /bin/bash
    - name: Set permissions for the user
      file:
        path: /home/rachna
        owner: rachna
        group: rachna
        mode: '0755'

Terraform — EC2 with Tags and Volume
